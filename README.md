# Grimwild: Community Edition (FVTT v13/14)

*Item, Journal, and RollTable Compendiums for Grimwild Community Edition*

**(WIP, playable but missing a few things)**

### Instructions

Items are found in their own compendiums, with the "CE" prefix.

When adding talents to a character sheet, *do not* use the "Compendium" button on the sheet; this will open the legacy Grimwild 1.4 compendium.
